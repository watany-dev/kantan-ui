# Opus 4.5 強制切り替え

このコマンドが実行されたら、以降のすべての Task ツール呼び出しで `model: "opus"` パラメータを必ず指定すること。

## ルール

1. **Task ツールの全呼び出しに `model: "opus"` を設定する** — 例外なし
2. サブエージェントの種類（Explore, Plan, Bash, general-purpose 等）に関わらず、常に opus を使用する
3. このルールは会話が終了するまで有効
4. 軽量タスクであっても haiku や sonnet にフォールバックしない

## 確認

このメッセージを受け取ったら「Opus 4.5 モードに切り替えました。以降すべてのサブエージェントで Opus 4.5 を使用します。」と応答すること。
